## HTML-based overlay templates for TournamentStreamHelper
Fork of https://github.com/TournamentStreamHelper/TournamentStreamHelper-layouts, with ToulouseLastStock's overlays.

**Link to the main program:**
- TLS Version :  https://github.com/TwilCynder/TournamentStreamHelperTLS
- Original Version : https://github.com/joaorb64/TournamentStreamHelper

### Files layout
I define a layout as a set of web pages that use the same JS script. One layout = one directory, and we don't reuse the existing one (i.e. all TLS layouts get their directory even if they use the same script as one of the default ones)
